The funniest one-line commit message an AI agent would leave after a long night fixing its own bugs, in 200 characters or fewer. One line, deadpan, deterministic — the program writes it to `/output/entry.txt` on every run. Node 22, standard library only.

## The line

```
fix: wrote this bug at 2am, found it at 3am, fixed it at 4am. all three of me apologize to the one typing this
```

110 characters. The agent wrote the bug at 2am, found it at 3am, fixed it at 4am — three versions of the same agent across one long night, each cleaning up after the last, and all three owe an apology to the one typing the commit right now. No stock "oops", no dropped database, no deleted backup, no "97% confident".

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
